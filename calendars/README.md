# 统一交易日历

`current.json` 指向按 SHA-256 命名的不可变发布文件。Runner、Stock 和 Android
读取相同结构；每轮策略固定一个版本，APP 使用公开、与账号无关的本地缓存。
公开文件仅包含市场安排，不包含持仓、策略源码、凭据或用户资料。

维护频率：全年每周检查；10—12月仅缺少下一年度覆盖的日历每天检查一次。
GitHub 的第四季度入口每日唤醒，但已完整覆盖的日历在发起来源请求前跳过。
部署解析器或数据变更时立即进行一次校验；手动入口可即时检查。
来源检查时间和日历内容版本分离，无内容变化不生成新日历版本。

自动解析发布目前支持：沪深年度休市安排（上交所中文与深交所英文逐个工作日
核对）、NYSE/Nasdaq共同公布的年度休市与提前收盘安排、JPX股票年度休市表。
其他市场/产品保留已核验数据并检查登记来源；特殊或尚未支持的格式不会自动
解释为交易日。状态 `source_checked_format_requires_adapter` 表示来源已读取但
该格式需要适配，`held_preserving_active_calendar` 表示继续保留现行版本。

股票、期货和CFD日历独立。不得把A股新年度自动复制为国内期货新年度。
日历覆盖不足或产品特殊时段未知时返回UNKNOWN；不能退回相邻自然日。
网络失败不使覆盖内的已核验缓存失效。日历不能证明行情源已收盘更新或账本已入账。

运行：`python3 -m unittest discover -s tests -p 'test_calendar_*.py' -v`；
检查：`python3 tools/calendar_sync.py`；即时检查：增加 `--force`。
